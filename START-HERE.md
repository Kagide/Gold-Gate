Gold Gate — Responsive and SEO update v1.1.0

Extract this ZIP into a new folder. Stop any older development server with Ctrl+C.
Open PowerShell in the gold-gate folder and run:

npm.cmd ci
npm.cmd run dev

Open http://localhost:3000 and press Ctrl+0 to reset browser zoom.
If npm.cmd is not found, restart VS Code/PowerShell after installing Node.js.
If Node is installed in the standard folder, temporarily run:
$env:Path = "C:\Program Files\nodejs;" + $env:Path

The README includes setup, contact delivery and production instructions.
Read docs/SEO-LAUNCH.md before public launch. Set NEXT_PUBLIC_SITE_URL to the final domain and rebuild to enable production URLs and indexing. Email delivery requires approved provider credentials.

The owner presentation and QA report are included. No site has been published.
